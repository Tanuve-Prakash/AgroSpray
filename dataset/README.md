# dataset

Put your training images here, one folder per class (folder name = class label):

```
dataset/
  betel_healthy/            betel_diseased/
  malabar_spinach_healthy/  malabar_spinach_diseased/
  potato_healthy/           potato_diseased/
```

Keep the word `healthy` in every healthy class name; the robot code uses it to decide.
Images are not committed to git (see `.gitignore`).
